## 1. Role Overview

### 1.1 Purpose
The Security Guard role is specifically for security personnel. This role has special payroll configuration with NO government deductions (SSS, PhilHealth, Pag-IBIG) as security guards typically have different employment arrangements.

### 1.2 Responsibilities
- Clock in and out for each shift
- Maintain accurate attendance records
- View personal attendance and payroll
- Report security-related issues through appropriate channels
- Keep personal information updated

### 1.3 Key Difference from Other Roles
**No Deductions:** Unlike other employees, Security Guards do NOT have:
- SSS deductions
- PhilHealth deductions
- Pag-IBIG deductions

Your **Gross Pay = Net Pay** (you receive full amount)

## 2. Special Status: No Deductions

### 2.1 Why No Deductions?

Security Guards typically:
- Have separate security agency arrangements
- May have different benefit structures
- Are handled outside standard government deduction programs
- Receive full gross pay without automatic deductions

**Important:** This is set by Admin/Super Admin. Do not change this setting.

### 2.2 Your Payslip Simplified

**Regular Employee:**
```
Days Worked: 7
Daily Rate: ₱500
Basic Pay: ₱3,500
SSS: -₱157.50
PhilHealth: -₱122.50
Pag-IBIG: -₱100.00
Net Pay: ₱3,120.00
```

**Security Guard:**
```
Days Worked: 7
Daily Rate: ₱500
Basic Pay: ₱3,500
Deductions: ₱0.00
Net Pay: ₱3,500.00 ← Full amount!
```

### 2.3 If You Want Deductions

If you need government contributions (SSS, PhilHealth, Pag-IBIG):
1. Contact HR Department
2. Request change in employment status
3. This may require changing from Security Guard position
4. Admin will update your deduction flag
5. Deductions will start next payroll cycle

**Note:** This is a significant change. Discuss with HR thoroughly.

## 4. Daily Attendance Procedure

### 4.1 Clocking In (Start of Shift)

**When to Clock In:**
- At the beginning of YOUR assigned shift
- Not when other employees arrive
- According to your security schedule

**Process:**
1. Arrive at your security post/station
2. Open the attendance system
3. **QR Code Method (Recommended):**
   - Click "Scan QR Code"
   - Hold your QR card to camera
   - Wait for confirmation
4. **Manual Method:**
   - Select your name
   - Click "Clock In"
   - Confirm location

**Verify:**
- Time is correct
- Location shows your assigned post
- You see "Clock In Successful"

### 4.2 Clocking Out (End of Shift)

**When to Clock Out:**
- At the end of YOUR assigned shift
- When relieved by next guard
- Do not clock out early

**Process:**
1. Same as clock in
2. Scan QR code or click "Clock Out"
3. Verify time recorded
4. Confirm successful logout

**For Shift Handover:**
- Clock out only when replacement arrives
- Ensure proper turnover
- Both guards should have accurate times

### 4.3 Multiple Posts (If Applicable)

**If You Patrol Multiple Locations:**
1. Primary post is your "home" location
2. Clock in at primary post
3. If system allows, note patrol locations
4. Clock out at primary post

**Important:** Tell Admin if you're assigned to multiple locations so they can set up correctly.

### 4.4 Night Shift Considerations

**Night Shift Clock In:**
- Clock in at scheduled night shift start time
- System records 24-hour format
- Example: 10:00 PM shows as 22:00

**Night Shift Clock Out:**
- May be next calendar day
- Example: Clock in 22:00 (10 PM), Clock out 06:00 (6 AM next day)
- This is normal for night shifts

**Overtime for Night Shift:**
- Night differential may apply
- Check with Admin if night shift has special rates

## 5. Viewing Your Records

### 5.1 Viewing Attendance History

**Navigate to:** Your dashboard or Attendance section

**What You'll See:**
- Calendar showing all days
- Days marked as:
  - Green: Present (shift worked)
  - Red: Absent (no show)
  - Yellow: Late (arrived after shift start)
- Time in and time out for each day

**Checking Your Shifts:**
1. Select month to view
2. Review each day
3. Verify times match your schedule
4. Check for any missing entries

### 5.2 Viewing Your Payroll

**Navigate to:** Payroll or Reports section

**Your Security Guard Payroll Shows:**
- Days/shifts worked
- Your daily rate
- Basic pay calculation
- **Deductions: ₱0.00**
- **Net Pay: Full gross amount**

**Example:**
```
Employee: Juan Dela Cruz
Position: Security Guard
Period: March 1-15, 2026

Days Worked: 15
Daily Rate: ₱550
Basic Pay: ₱8,250

SSS Deduction: ₱0.00
PhilHealth Deduction: ₱0.00
Pag-IBIG Deduction: ₱0.00

Total Deductions: ₱0.00
NET PAY: ₱8,250.00
```

**If You See Deductions:**
- This is an error
- Contact Admin immediately
- Reference this SOP that Security Guards have no deductions
- Request correction

## 6. Understanding Your Pay

### 6.1 How Your Pay is Calculated

**Formula:**
```
Days Worked × Daily Rate = Your Pay
```

**Simple - No Deductions Subtracted!**

**Example Calculations:**

| Days Worked | Daily Rate | Your Pay |
|-------------|------------|----------|
| 15 days | ₱500 | ₱7,500 |
| 15 days | ₱550 | ₱8,250 |
| 15 days | ₱600 | ₱9,000 |
| 30 days | ₱500 | ₱15,000 |

### 6.2 Special Situations

**Partial Day:**
- If you work partial shift
- May be counted as half day (0.5)
- Pay = 0.5 × Daily Rate

**Overtime (If Applicable):**
- Not all security guards have OT
- If enabled: Hours beyond shift × Rate
- Check with supervisor

**Holiday Pay (If Applicable):**
- Working on holidays may have special rate
- Check company policy
- Ask Admin if holiday rate applies

### 6.3 If You Have Cash Advance

**Important:** Cash advance IS deducted even for Security Guards.

**Example:**
```
Basic Pay: ₱7,500
Cash Advance Deduction: -₱1,000
Net Pay: ₱6,500
```

**No Government Deductions, But:**
- Cash advance repayments still apply
- Any other company loans still apply
- Only SSS/PhilHealth/Pag-IBIG are waived

## 7. Support & Communication

### 7.1 Your Supervisor Chain

**For Security Guards:**
1. **Immediate:** Security Supervisor/Team Leader
2. **Operational:** Operations Manager or Admin
3. **Payroll:** Payroll Admin
4. **Issues:** Super Admin (for system problems)

### 7.2 Common Issues for Security Guards

**Problem: Wrong Location Showing**
**Solution:**
- Tell your Security Supervisor
- They will contact Admin
- Admin can correct location
- Common if you patrol multiple posts

**Problem: Cannot Clock In - "Outside Area"**
**Solution:**
- Verify you're at correct post
- Check with supervisor about location
- May need Admin to adjust geofence
- Use manual entry as backup

**Problem: Night Shift Times Wrong**
**Solution:**
- Example: You worked 10 PM - 6 AM
- System may show as two days
- This is normal - don't worry
- Pay will be calculated correctly
- Ask Admin if you want explanation

**Problem: Deductions Showing on Payslip**
**Solution:**
- This is an ERROR for Security Guards
- Contact Admin immediately
- Show them this SOP
- Request immediate correction
- Verify corrected before pay released
